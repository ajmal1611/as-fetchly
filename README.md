# AS Fetchly

Windows app to download YouTube and TikTok videos, playlists and whole profiles, in 144p up to 4K, with daily auto-download and video cutting. English and Urdu.

By [AS Forge](https://asforge.app).

## Download
Go to the [Releases](../../releases/latest) page and download the setup file.
Requires Windows 10 or 11 (64-bit).

## Notes
- If Windows shows "protected your PC", click More info, then Run anyway.
- Free plan: single videos up to 720p. Pro unlocks playlists, profiles, auto-download, cutting and 4K.
- Download only content you own or have permission to save.
